# مشاريعي البرمجية (Python Projects)

هذه مجموعة من المشاريع البرمجية التي قمت بتطويرها خلال رحلتي في تعلم Python وتحليل البيانات. 

## قائمة المشاريع:
1. **نظام تنسيق بيانات العملاء (Customer Data Processor):** يقوم بمعالجة النصوص، توليد أسماء مستخدمين، وتشفير البريد الإلكتروني.
2. **محاكي السوبر ماركت (SuperMarket System):** نظام بسيط لحساب الفواتير وإدارة الكميات.
3. **حاسبة سرعة السيارة:** تطبيق لمعالجة المدخلات والحسابات الرياضية.

## الهدف:
تطوير مهاراتي في البرمجة وتطبيق المنطق البرمجي لحل مشكلات محاسبية وبياناتية.
